# Mm Cnc

**الموقع المنشور: [mm-cnc.pages.dev](https://mm-cnc.pages.dev/)**

موقع عربي/إنجليزي لتحويل رسومات PNG وJPG وJPEG وWEBP وBMP إلى ملفات هندسية، مباشرة داخل المتصفح دون رفع الصور إلى خادم.

## ماذا يُنتج؟

| الملف | الاستخدام |
| --- | --- |
| PNG | صورة بالأبعاد الأصلية بالبكسل، مع الاحتفاظ بالخلفية أو الشفافية بعد إزالتها اختياريًا. |
| DXF | حدود مغلقة بوحدة الملليمتر، قابلة للاستيراد في AutoCAD وبرامج CAD المتوافقة. |
| SVG | حدود متجهية؛ يتضمن العرض والارتفاع الفعليين بالملليمتر. |
| STL | مجسم بارز من البكسلات الممتلئة؛ يُستورد كشبكة Mesh في برامج CAD، وليس ملف SLDPRT أصليًا. |
| G-code (`.nc`) | مسار محيطي عام فقط. يتطلب ضبط الأداة ونقطة الأصل والعمق والمحاكاة قبل التشغيل على ماكينة CNC. |

المعالجة تعتمد على استخراج حدود مناطق الصورة. الصور الفوتوغرافية تحتاج غالبًا إلى تنظيف أو تحويل إلى رسم عالي التباين للحصول على مسارات مفيدة. تبسيط الحدود يؤثر في DXF وSVG وG-code؛ مجسم STL يحتفظ بشكل البكسلات. الصور تبقى على جهاز الزائر.

## PNG وإزالة الخلفية الاختيارية

- **لا تبدأ إزالة الخلفية تلقائيًا.** اختر طريقة الإزالة ثم اضغط الزر. تغيير الصورة أو اللون أو الحساسية وحده لا يشغّل الإزالة.
- **فصل ذكي:** يفصل الأشخاص والأجسام محليًا داخل المتصفح. يحتاج أول استخدام تنزيل أدوات بحجم نحو 190 MB، ويحفظ النموذج في ذاكرة المتصفح عندما تتوفر مساحة. قد يلزم تنزيله مجددًا إذا مُسحت الذاكرة. لا تحتاج هذه المعالجة إلى مفاتيح API أو اشتراك منفصل لدى مزوّد ذكاء اصطناعي.
- **خلفية موحّدة:** مناسبة للشعارات والرسومات؛ كشف لون الحواف أو اختيار اللون يدويًا، وضبط الحساسية والنعومة، مع خيار حماية المناطق الداخلية أو إزالة اللون من كل الصورة.
- معاينة الأصل والنتيجة، إلغاء المعالجة، واستعادة الأصل متاحة. إعدادات كل محاولة تُطبّق على الأصل حتى لا تتراكم الخسارة.
- يحفظ PNG أبعاد الصورة الأصلية، وليس دقة معاينة المسارات. إعدادات التباين والقياس بالملليمتر لا تغيّر PNG؛ إزالة الخلفية الاختيارية تؤثر في الصورة المصدّرة وفي استخراج المسارات.
- الفصل الذكي قد يفقد تفاصيل رفيعة أو يترك حواف من لون الخلفية؛ عاين النتيجة قبل استخدامها. يعتمد على متصفح حديث وقد يستغرق وقتًا على الأجهزة الضعيفة.

التفاصيل والتراخيص: [أدوات إزالة الخلفية](src/background/README.md)، [إشعارات المكونات](public/licenses/background-removal-NOTICE.txt). المعالجة لا ترفع الصور إلى خادم.

## الحسابات والاشتراك السنوي

توجد واجهة عربية/إنجليزية لحساب المستخدم، وحصة 10 صور مختلفة لكل حساب، ثم اشتراك 30 USD لسنة تقويمية عبر شام كاش بعد مراجعة المطوّر للحوالة. إعادة تصدير الملف نفسه بصيغ متعددة لا تخصم صورة إضافية. يبدأ الاشتراك عند اعتماد الدفع، وتجديد الاشتراك الساري يضيف سنة إلى نهايته.

الخدمة مفعّلة على Cloudflare Pages مع Supabase، ويعمل تسجيل الدخول عبر GitHub. واجهة تسجيل الدخول بالبريد وكلمة المرور معطّلة إلى حين إعداد خدمة بريد مناسبة واختبارها. متغيرات البناء العامة موجودة في `.env.example` وتُضبط في إعدادات بناء Cloudflare Pages. لا تضع مفاتيح سرية في هذه المتغيرات. راجع [دليل الخدمة](supabase/README.md) و[حالة النشر والتحقق](supabase/DEPLOYMENT.md).

المعالجة الحالية داخل المتصفح؛ الحسابات تحفظ الرصيد وصلاحيات الاشتراك، لكنها لا تمنع تقنيًا نسخ كود المعالجة أو تجاوز الواجهة بواسطة عميل معدّل. فرض حماية صارمة يحتاج نقل التصدير أو المعالجة إلى خادم يتحقق من الصور. حدود الخطة المجانية للخدمة وسياسة إيقاف المشاريع غير النشطة تظل مطبقة.

## التشغيل المحلي

يتطلب Node.js 22 أو أحدث.

```bash
npm ci
npm run dev
```

افتح العنوان المحلي الذي يظهر. لفحص الملفات والبناء:

```bash
npm test
npm run build
```

## النشر على Cloudflare Pages

يرتبط Cloudflare Pages بمستودع GitHub، ويبني فرع `main` بالأمر `npm run build` وينشر مجلد `dist`. استخدم Node.js 22 واضبط `VITE_BASE_PATH=/`، مع `VITE_SUPABASE_URL` والمفتاح العام `VITE_SUPABASE_ANON_KEY`، و`VITE_ENABLE_GITHUB_AUTH=true` و`VITE_ENABLE_EMAIL_AUTH=false`. تفاصيل الإعداد والتحقق في [سجل النشر](supabase/DEPLOYMENT.md).

اضبط عنوان الموقع في Supabase على `https://mm-cnc.pages.dev/`، واسمح بإعادة التوجيه إلى العنوان نفسه وإلى `https://mm-cnc.pages.dev/#account`. بيانات الحسابات والحصص والاشتراكات تبقى في Supabase.

الملف [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) مخصص لتحويل رابط GitHub Pages القديم إلى الموقع الجديد فقط؛ لا يبني التطبيق المدفوع. يحتاج متغير المستودع `PAGES_REDIRECT_URL=https://mm-cnc.pages.dev/`. نشر هذا التحويل والتحقق منه ما زالا ضمن خطوات الانتقال الموثقة في سجل النشر.

الخطط المجانية لها حدود استخدام وسياسات قد تتغير؛ لا يوجد ضمان لاستضافة مجانية أو متاحة إلى الأبد. يبقى المصدر في مستودع GitHub العام مرئيًا للآخرين. لا تضع فيه أسرارًا أو مفاتيح توقيع أو ملفات عملاء.
